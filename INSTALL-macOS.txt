FlexDL — macOS copy-paste installation
========================================

Requirements:
- Node.js 22 or newer
- Python 3
- Homebrew
- A Chromium-based browser


1. INSTALL AND START FLEXDL

Open Terminal, copy the complete block below, paste it, and press Return:

brew install ffmpeg
mkdir -p "$HOME/Applications"
git clone https://github.com/hypervalentdotcom/Flex-dl-Chromium.git "$HOME/Applications/FlexDL"
cd "$HOME/Applications/FlexDL"
./Start.command


2. LOAD THE EXTENSION

Copy this address into the Chromium address bar:

chrome://extensions/

Enable Developer mode, click "Load unpacked", then select:

~/Applications/FlexDL/extension


3. COMMANDS FOR LATER

Start FlexDL:

cd "$HOME/Applications/FlexDL"
./Start.command

Stop FlexDL:

cd "$HOME/Applications/FlexDL"
./Stop.command

Check its status:

cd "$HOME/Applications/FlexDL"
./Status.command

Update FlexDL and restart it:

cd "$HOME/Applications/FlexDL"
./Stop.command
git pull --ff-only
./Start.command


ZIP FALLBACK

The Git installation above is recommended because it avoids the quarantine
metadata added to browser downloads. If you deliberately use the macOS ZIP,
open Terminal in the extracted FlexDL folder and run:

xattr -dr com.apple.quarantine .
chmod +x ./*.command
